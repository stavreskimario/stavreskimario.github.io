# Selected stone roughness sources

These six Non-Color PNGs retain the spatial grain of the original CC0 ambientCG Granite005A and Travertine009 maps. The selected bounded B profiles have nominal ranges InteriorGranite0.30–0.48, MilfordGranite0.55–0.78 and Travertine0.60–0.78, applied with multiplier1. Eight-bit rounding produces the measured extrema in [roughness-provenance.json](roughness-provenance.json). Full sources are2048px; existing fallback derivatives are512px.

These ranges are interpreted finishes, not measured station samples. All nine original source files, architectural UV0, colour, grain scale and normal maps remain unchanged. Marble018 and marble-family polish remain unchanged. [The appearance review](../../review/phase5/material-finish/README.md) retains source statistics, actual matched-camera controls and the reason the preceding near-mirror response was changed.

The provenance file verifies all six retained bytes/hashes against the selected generated outputs, the three original roughness maps and the exact generator. KTX2 encoding, source-channel preservation and final runtime/browser publication are separate evidence; source selection alone does not establish delivery or final photographic fidelity.
