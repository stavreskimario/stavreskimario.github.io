# Whole ordinary-gallery finish source checkpoint

This editable Blender addon adds98 fitted finish volumes along both107m gallery edges and the fourteen stairs outside the retained Platform5 pair:56 stringer faces,28 landing faces and14 gallery fascia segments. Existing treads, rail profiles, source positions, lifts, Main floor/prisms and all current Platform5 finish remain unchanged. No continuous gallery wall or generic dropped ceiling is introduced: primary photographs show an open-sided lower gallery.

The v4 addon adds a small `33rd STREET` destination board on two actual ceiling stems. Both sides use independent outward-facing readable lettering backed by the opaque board, with2.2376m minimum head clearance. The destination-sign family is supported by PRR1910PDF53; exact placement, size, typeface and hue are inferred. Source geometry/contact/clearance checks are recorded separately from final light, encoded/runtime and browser checks. Final lighting and encoded/static acceptance are retained in [acceptance](acceptance/README.md); publication follows the matching deployment.

`material/gallery-floor-material.blend` contains the authored material and all three packed source images. The modern ambientCGConcrete034 PBR set is CC0; it is an appearance interpretation for the already-qualified neutral gallery floor, not an authenticated historic sample. Physical tile1.1×0.55m, normal strength0.22; the current floor's mean linear albedo is retained. Blender4.3 drops the authored legacy MixRGB multiplier during glTF export, so the packaging helper restores that exact multiplier through standard glTF baseColorFactor; original source-image pixels remain unchanged. Sample material geometry is never appended to the station. The binder preserves all station geometry/BIN, UV, frames, other materials, baked AO and illumination.

Primary evidence and modern material rights are listed in the evidence/material records. Original builders retain actual external work paths and require rebinding to the byte-pinned source inputs, including the retained original P5-family packet; this is not an assertion that the entire neighboring station source is duplicated here. `model/finish-addon.glb` is the exact small raw architectural addon. The accepted independent4K/128sample gallery lighting preserves authored hard-face normals before transport; rejected smoothing is retained as a separate control.
