# Ordinary arrivals: source checkpoint

This is a compact source/research archive for the first eight ordinary arrival pairs. It contains no duplicate Blender scene, raw GLB or historical reference raster. The canonical and public runtime files are handled by separate reviewed promotion steps.

- [Authoring helper](../../../../../penn-station-1935/model/repair_arrivals_access.py): standalone `--source`, `--out` and optional `--inputs` CLI, fixed baseline and input-hash guards, external outputs only.
- [Architectural evidence and limits](../../../../../penn-station-1935/model/arrivals-evidence.md): supported form, interpreted details and unfinished areas.
- [Frozen inputs](sourceinputs/expected-inputs.json): exact original-byte hashes. Large JSON files are gzip archives; decompress before comparing their original hashes.
- [Archive manifest](archive-manifest.json): retained payload hashes and uncompressed chronology.

The input editable source is SHA256 `f2e5a0e382b5d6771030055ed527546005cd18d2a3e2d77f204d570c0a9cc588`, published in checkpoint `d6d6cb1`. The frozen candidate's original source proof is retained byte-for-byte in `frozen-candidate-source-proof.json.gz` (uncompressed SHA256 `715435918224899607c4241bc41b80afc7c5141a1d243f8b6724a00de2035146`). Its original geometry and fixture-recipe hashes are in `frozen-candidate-READY.json`.

The historical proof files retain original work paths as provenance data. Those paths are not executable dependencies. The helper reads only its explicit source/input arguments and writes into its new external output directory. Reference rasters remain outside this archive; their source identifiers, publication details and hashes are preserved in the evidence descriptors.

The first-eight raw source candidate passed closure/winding, exact retained attributes and independent source route/loadpath checks. All 96 stair/lane routes and 39,696 samples per full/low variant, 9,084 corridor samples, complete fixture mounts, 47 lower bearing centres and 525 upper-cap footprint samples were checked with actual relocated platform fixtures and no collider exclusions. Contact/route proof does not certify historical fabrication or structural capacity. Final optimized rendering, illumination, desktop movement and live deployment remain separate gates.

The northern research guard, retained P9/LIRR deck, unresolved upper transfers, held western Main floor and unfinished streetward routes remain explicit. Do not describe this checkpoint as complete station circulation or a certified 1935 replica.
