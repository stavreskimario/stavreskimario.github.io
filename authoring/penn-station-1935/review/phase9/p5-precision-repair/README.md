# P5 eight-owner precision repair

This external checkpoint repairs transport of the six reviewed west P5 curved rails and two lower haunches. The standard full/fallback module failures remain frozen under `arrivals-p5-encoded-review-v1`: the global 1.63 mm position grid collapsed new thin faces, while fallback simplification failed 416/562 unchanged 1 mm tube-profile samples. Neither contact nor profile thresholds were widened.

`repair_precision.mjs` uses the pinned accepted raw 25bc source, selection 80569caf and qualified summary 0962e429. It removes only the exact old eight-owner render-index union. Original BIN, accessors, views, nodes, materials and all unowned decoded index values/order stay exact; the fourteen flat finish panels stay exact. Original render faces are removed before replacement, so the old curved faces cannot remain as duplicate draws. Forty-six fallback shared-cap triangles are ambiguous only between the six owned rails; the complete owned union has no ambiguity crossing to an unowned component.

Six source rails have identity frames, matching attributes and common node metadata. Their exact Float32 attribute bytes concatenate into one primitive with sequence-preserving adjusted indices and recorded source spans. Two haunch nodes retain their original local Float32 vertices and literal translations. Meshopt ATTRIBUTES with no filter and INDICES transport every appended byte exactly. The module grows from 4 to 7 nodes/meshes and 7 to 10 material draws. Source positions, normals, UVs and world triangle corners are exact; this is batching exported Blender geometry, not generating architecture.

All seven existing material definitions, thirteen KTX2 files and two filtered GI maps remain byte-for-byte unchanged. There is no new bake, texture encoding, canonical edit, root write, GPU or browser execution. The two repaired standalone modules are in `arrivals-p5-optimized-precision-v1`; root must append them to matching retained D06 bases, not an already integrated concourse.

`verify_precision.mjs` independently decodes the written files and recomputes source spans, unowned index preservation, closed topology, positive volume, zero degeneracies, finite outward/unit normals, 562 two-sided tube profiles, 12 complete endpoint caps, 4 connecting rings, 46 actual receiver regions, 88 adjacencies, 12 source-required rail/newel/finial comparisons and positive interior witnesses at finials 004/006. Source 20 µm cap/ring and 1 mm profile gates remain unchanged; actual encoded receiver regions retain the existing 2 mm bound. The separate source-only fixture diagnostic remains separately qualified.

`validate.mjs` records actual glTF validation. Each repaired module has 0 errors/16 warnings; the complete warning codes, messages and pointers match the standard module exactly. Dead original index payloads remain preserved as provenance; the rendered primitives reference only retained unowned indices and the exact replacement sources.

`wire-size-comparison.json` measures standalone gzip9 transport: full 840,619 bytes, fallback 1,083,962 bytes, combined 434,189 bytes more than standard. These are standalone figures; root must measure assembled D06 staging independently. Three additional draws and retained source precision are reported without an FPS claim.

Historical qualifications remain: lower arrivals/Exit stair family, inferred 150 mm radius and fabrication, unauthenticated exact P5 camera identity, and upper haunch held. Local/source/CPU acceptance does not establish final photorealism, complete gallery, structural capacity, native browser or publication acceptance.
