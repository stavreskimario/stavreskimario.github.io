# Connected entrance pipeline preparation

This checkpoint prepares isolated `arcade-enclosure` lighting, an arcade-centre HDR reflection capture, exact closed-shop-glazing collision classification and bounded replacement of old granite/window/travertine surfaces. It does not publish new entrance geometry or establish final materials, route, performance or browser acceptance.

The reverse-interface removal fix changes coverage bookkeeping only: a face already positively matched to retained oriented geometry now contributes to protected source coverage. Index selection, tolerances, matching and payloads are unchanged. The scoped arcade matcher and 38 controls retain hard failures for unexplained geometry; the platform regression remains separate.

The [15 provenance control groups](denoise-controls.json) test exact source/report hashes, independent 4096/512px maps, linear input, retained HDR and coexistence with the earlier platform/access/circulation/arrivals atlases. These are synthetic validator controls, not a new bake.

The actual entrance authoring and its independent preservation/closure review are separate pending work. The existing public platform checkpoint remains the accepted runtime.
