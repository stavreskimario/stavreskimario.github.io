# Maps

The embedded day and destination maps use Google Maps. External location and directions links default to Google Maps. A shared Google Maps / Apple Maps selector updates all external map links and saves the preference on the current device using localStorage. Google Maps embeds stay unchanged when the external provider changes.

URL syntax: https://developers.google.com/maps/documentation/urls/get-started and https://developer.apple.com/library/archive/featuredarticles/iPhoneURLScheme_Reference/MapLinks/MapLinks.html
